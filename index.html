  1. Work Integrated Learning

    Tender Scrapper

    Data Science Academy — Team project

    Aug 2026 – Present

    A platform that collects South African government tenders and helps companies find the ones worth bidding on. It is made up of separate services that share one database and one sign-in system.

    Built by me

    • Signup API: business-only registration. Free email providers are rejected, an account is created only after a single-use verification link is opened, and requests are rate-limited.
    • Smart Tender Alerts API: scores each open tender from 0 to 100 against a company's business profile, explains the score in plain language and saves strong matches as notifications. A background scan repeats this every 5 minutes.
    • Business Profile API: keeps one profile per company, built from the company's uploaded business documents. The other services use it to match tenders.
    • Tender category classifier: a scikit-learn model that predicts a tender's procurement category. Its top three suggestions include the correct category for 72.5% of the 1,342 tenders held back from training.
    • Overview API: the statistics behind the dashboard's Overview page, such as open tenders, tenders closing this week, and tenders by province and category.
    • Docker and CI/CD: packaged each of my services with Docker and Docker Compose, and set up GitHub Actions pipelines that run the tests on every push and deploy the service once they pass.
    • Testing and monitoring: automated tests with pytest for every service, and health-check endpoints that report whether the shared database is reachable.

    Team contribution

    • AI search: added Redis caching, embeddings and vector search to the team's AI tender assistant, so it finds relevant tenders by meaning as well as by keywords.
    • AI chat: made the assistant answer tender questions straight from the platform's database, and made it faster. Users can ask it to show their Smart Alerts matches, and follow-up questions keep the conversation going.
    • Smarter searches: connected the assistant to my tender category model and to each user's profile, so chat searches stay in the right category and provinces.
    • Business documents: taught the assistant to read the commodity list from a company's Central Supplier Database (CSD) report.
    • Privacy and security: kept each user's chat history separate, stopped logging chat text, deleted a user's data with their account, and hardened the service with a CORS allowlist, a non-root container, pinned dependencies and automated dependency audits.
    • AI workspace front end: showed Smart Alerts match reasons in the dashboard radar chart, listed every match on the Tender Board with the best first, and made the chat and match scores work well on phones.
    • Web front end: I worked with the team on the platform's web front end, built with HTML, CSS and JavaScript.

    In progress

    The platform is still being developed and is not publicly available yet.
