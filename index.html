Projects

Tender Scrapper

Team project

A platform that collects South African government tenders and helps companies find the ones worth bidding on.

Services I built

  • Signup API Business-only registration with single-use email verification links and rate limiting.
  • Smart Tender Alerts API Scores each open tender from 0 to 100 against a company's profile, explains the score and saves strong matches as notifications.
  • Business Profile API Builds each company's profile from its uploaded business documents.
  • Tender category classifier A scikit-learn model that predicts a tender's category. Its top three suggestions include the right one for 72.5% of tenders it never saw in training.
  • Overview API The statistics behind the dashboard's overview page.

I also worked on the platform's web front end.
